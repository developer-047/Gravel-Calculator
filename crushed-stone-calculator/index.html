Crushed Stone Size Chart

Crushed stone is graded by size code: #57 (¾–1″) is the common driveway surface and French drain stone, #411 and #304 are base blends, and #8 (3/8–½″) is a topdressing.

Size Code Typical Density (lb/ft³) Typical Applications
#1 100–120 Largest — erosion control, larger drainage
#3 100–120 Larger stone — drainage, accent
#4 95–105 Medium — concrete mix, landscaping
#8 3/8″–½″ Topdressing, asphalt mix
#411 110 Base material, road construction
#304 105 Leveling agent, filler
#57 100 Driveway surface, French drain, landscaping
Crusher Run 105 Base material, compacts well

Which size for which project?

Use crusher run or #304 for the 4″ base, #57 or #411 for the 2″ surface, and #8 for topdressing between pavers or on walkways.

Base/Subgrade: Crusher Run or #304 — compacts well, provides stable foundation.

  • Highway base, driveway base, paver base

Surface/Topping: #57 or #411 — good drainage, interlocks when compacted.

  • Driveway surface, walkways, French drain fill, landscaping

Decorative/Topdressing: #8 — smallest fraction, used for finish coats.

  • Walkway topdressing, between pavers, playground filler

Density by Size Code

At typical compacted densities, #57 stone weighs 100 lb/ft³ (1.35 short tons/yd³), #411 110 lb/ft³ (1.49 tons/yd³), and #304 and crusher run 105 lb/ft³ (1.42 tons/yd³).

Compacted density:

  • #57: 100 lb/ft³ (~1.35 short tons/yd³ · ~1.22 metric tonnes/yd³)
  • #411: 110 lb/ft³ (~1.49 short tons/yd³ · ~1.35 metric tonnes/yd³)
  • #304: 105 lb/ft³ (~1.42 short tons/yd³ · ~1.29 metric tonnes/yd³)
  • Crusher Run: 105 lb/ft³ (~1.42 short tons/yd³ · ~1.29 metric tonnes/yd³)

Loose density:

  • #57: ~95 lb/ft³
  • #411: ~105 lb/ft³
  • #304: ~100 lb/ft³
  • Crusher Run: ~100 lb/ft³

Base vs Surface Stone

A typical residential driveway uses a 4″ base of crusher run or #304 and a 2″ surface of #57 or #411, for 6″ total.

Base layer (recommended 4″):

  • Crusher Run or #304 — compacts into solid foundation
  • 4″ typical depth for residential driveways
  • Provides load distribution and frost protection

Surface layer (choice of size and depth):

  • #57 — 2″ typical, good drainage, interlocks when compacted
  • #411 — 2-3″, finer material, more stable surface
  • Total typical driveway thickness: 6″ (4″ base + 2″ surface)

FAQ

What's the difference between #57 and #411?
#57 is ¾″–1″ crushed stone; #411 is a blended mix of stone and fines that compacts more densely. #57 drains better; #411 packs more tightly.
What is Crusher Run?
Crushed stone fines that compact into a solid base. Used under pavers, driveways, and as a base before applying surface stone.
How many yards in a ton of #57 stone?
~0.74 cubic yards per short ton (at 100 lb/ft³: 2,000 lb ÷ 100 lb/ft³ = 20 ft³ ÷ 27 ft³/yd³ = 0.74 yd³).
What depth for a driveway base?
4″ of crusher run or #304 is typical for residential driveways. Add 2″ of #57 or #411 as surface.
Can I use #57 for a driveway base?
#57 can be used for a driveway base, but crusher run/compacted #304 is preferred for load-bearing capacity. #57 is better suited for surface or drainage.
