# Keyword Research — Pro Gravel Calculator

> **Research date:** 2026-11-01
> **Market assumed:** United States, English (`hl=en`, `gl=us`), with secondary English-market opportunities.
> **Data sources:** Google Autocomplete (`suggestqueries.google.com`, firefox client, en-US), live Google result sets, and a manual review of competing pages.
> **What is verified vs estimated:** Autocomplete confirms that a query is *typed often enough to be suggested*. It does **not** provide volume. No keyword volume, CPC, keyword-difficulty or traffic number is stated in this report because no reliable source for those numbers was available. Competition levels are **qualitative analyst estimates** based on the pages occupying the results, not on a difficulty score.

## 1. How to read this document

### Evidence labels

| Label | Meaning |
|---|---|
| `[Autocomplete]` | The query or a close variant was returned by Google Autocomplete on 2026-11-01 for the US market. |
| `[SERP]` | Dedicated pages targeting this query were observed in live Google results on 2026-11-01. |
| `[Site]` | Demand is inferred from the existing site's own content and query-param features; not independently verified. |
| `[Estimate]` | Strategic judgment. |

### Competition scale (qualitative)

| Level | Definition used here |
|---|---|
| **Low** | Few dedicated pages observed; results include forums, general articles, or thin tools. A strong, focused page can compete. |
| **Medium** | Several dedicated pages exist, but top results are not all from dominant calculator authorities. Requires a genuinely better page plus internal links. |
| **High** | Results are dominated by large calculator authorities (Omni, Inch, CalculatorSoup, GigaCalculator) and/or multiple mature clusters. Head-term victory is a long game. |
| **Very High** | Reserved for `gravel calculator` and `how much gravel do I need`; broad, heavily served, and expensive to displace. |

### Intent scale

- **Tool / transactional** — user wants an answer now, from a calculator.
- **Commercial investigation** — user is comparing materials, costs or suppliers before buying.
- **Informational** — user wants to understand a concept, depth, weight or method.
- **Local / commercial** — user wants a supplier or installed price near them. **Not a target for programmatic city pages** (doorway risk).

## 8. Location-specific opportunities (and what not to do)

| Keyword type | Examples | Recommendation |
|---|---|---|
| "near me" cost queries | `gravel cost per ton near me`, `gravel cost per yard near me` | **Do not build city pages.** A calculator has no local entity or address. Add a "local price variability" section and a supplier-quote CTA. |
| Country variants | `gravel calculator uk`, `gravel calculator canada`, `gravel calculator australia` | Validate demand first (UK and AU appear in Autocomplete). If pursued, build **one genuine regional version** with local units, terminology, prices and suppliers — not 50 cloned city pages. |
| State-level cost pages | `gravel cost in Texas` | High doorway risk and no verified data. Avoid until you have real regional price data and a reason to exist. |
| Delivery queries | `gravel delivery cost` | Serve with a delivery-cost field in the cost calculator. Do not create a "delivery company" page. |

**Doorway-page warning:** a page per state or per city with the same calculator and swapped place names would violate the brief's rules and Google's spam policies. This report does not recommend it.

## 9. Low-competition opportunities (highest near-term ROI)

These are the queries where the observed results are weakest relative to the value of the answer. All competition ratings are estimates.

| **Tons ↔ yards conversion** | High demand, but conversion is usually a paragraph inside a calculator page. | Add a dedicated conversion block and table on `/gravel-calculator-tons/`; consider a standalone converter later. |
| **Depth-by-application** | Competitors publish depth tables but few make them interactive presets. | Preset buttons: path 2", patio 3", driveway base 4", driveway top 2", French drain 12". |
| **#57 / #411 / crusher run** | Generic "crushed stone" pages rarely break out size codes. | Presets inside `/crushed-stone-calculator/`; add a size chart. |
| **100 ft / 200 ft / 20×20 driveway examples** | Concrete-dimension long tails are poorly served by generic calculators. | Add worked examples with exact outputs to `/driveway-gravel-calculator/`. |
| **"What will 4 tons cover?" reverse queries** | Most calculators only go area → tons, not tons → area. | Add a reverse mode to the tons page. |
| **Bulk vs bag cost** | Rarely modelled properly. | Add a comparison table and a "cheaper option" recommendation in the bag calculator. |
